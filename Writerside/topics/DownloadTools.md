## AB 下载管理器

GitHub [amir1376/ab-download-manager](https://github.com/amir1376/ab-download-manager)

```Bash
bash <(curl -fsSL https://raw.githubusercontent.com/amir1376/ab-download-manager/master/scripts/install.sh)
```

注： 默认下载线程只有8线程，下载速度并不快；可以增加线程数量提高下载速度。比如： 16、24、32、64 等
